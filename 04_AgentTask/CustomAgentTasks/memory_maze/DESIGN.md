# 真实室内地标记忆与顺序重访

## 训练目标

从局部视觉中学习地标与位置的关联，形成能支持重访的空间记忆，执行有序目标并抑制错误顺序。它关注的是室内空间记忆与导航；`memory_maze` 是沿用的原型名称，不宣称标准厨房是迷宫。

## Episode

1. 恢复固定版本 iTHOR 场景快照，采样可从原生可达位置看见的语义地标。只在评估器保存导航图和验证视点。
2. 代理在探索阶段移动和记录自己的文本记忆。
3. 代理执行 MEMORIZE，或探索预算耗尽；相机回到已知的初始位置。
4. 按指令顺序实际移动到地标附近并 MARK。地标必须可见，平面距离不超过 1.6 米。错误顺序计为非法交互并消耗一步。
5. 完成全部访问后停在最后地标附近 FINISH。提前 FINISH 终止但失败，耗尽总预算则截断。

L1：两个不同地标。L2：三个地标并重访第一个。L3：四个地标并重访第一个。场景可达位置、初始朝向和物体几何来自真实模拟器；代理没有完整图。课程只是结构性难度，需要另用模型表现标定。

## 训练模式与判分

- 成功终止奖励 1，失败 0；每步成本 0.1 / max_steps。严格成功同时要求顺序完整与最终位置，避免只回答一个编号取胜。
- 推荐先训练短路径访问，再增加有序目标、重访次数与探索预算压力。
- 对照：记忆字段保留/清空、探索阶段有/无、初始朝向变化，以及未见室内布局。不得把 oracle 的特权路线与观察策略直接作公平准确率比较。
- 指标：完整成功率、有序访问数、错误访问数、行动数；后续可增加观察策略相对有效路线的额外代价。

限制：能绕过探索阶段直接导航的策略仍可完成任务，因此这是空间记忆有潜在效率价值的环境，不声称每个样例的信息论上都必须记忆。模型不能获得地标坐标或 oracle 路线；地图仅用于生成可解任务和诊断。
