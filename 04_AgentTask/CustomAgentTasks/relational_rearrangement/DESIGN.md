# 第一人称空间关系重排

将符号图上的关系重排迁移到真实 iTHOR 台面。生成阶段用原生碰撞检查布置一个可拿取物体、一个受保护锚点和至少三个实际可放置位置。代理开始时关系不成立，存在可达且可执行的正确放置见证，也存在错误位置。

代理必须自己选择位置：PickupObject → 实际导航/转向 → PLACE(slot_N) → FINISH。PLACE 只放置真实手中物体到当前可见、未被遮挡且距离不超过 1.6 米的离散台面点，不会替代理选择满足关系的位置。PLACE 会将物体朝向恢复为 episode 初始朝向，使位置任务不受持物随相机旋转而改变的碰撞外形干扰；姿态推理由独立的 pose_alignment 任务负责。生成时还会拿着物体检查目标点，避免忽略持物遮挡。

方向采用固定世界参考系：东/西对应 x，南/北对应 z。画面只提供相机朝向罗盘和局部可见的编号标记；不提供目标坐标、完整地图或正确位置编号。相机转动不会改变关系定义。

L1 单一方向关系；L2 方向与近邻距离的合取；L3 两个方向与距离的合取。方向间隔至少 0.12 米，近邻上界 0.85 米。所有条件必须最终同时成立，真实 parentReceptacles 必须仍为指定台面，手为空，目标被实际拿取过，锚点及其他对象的姿态和触碰历史都保持不变。不能搬动锚点制造正确关系后再放回。

有价值的模式：同一关系切换初始视角，单关系到合取关系的课程，方向语言替换，错误位置与锚点触碰对照。开发/验证/测试分别使用不同厨房布局。当前是单目标的最小课程；多目标关系组合、模糊边界和更丰富的自然语言属于后续扩展。结构级别尚未通过模型表现校准。
