- `css/bulma.min.css`: upstream `original-version/static/css/bulma.min.css`, Bulma 0.9.1, retained unchanged. Bulma uses the MIT license; see `css/BULMA-LICENSE.txt`.

The project-specific player and `style.css` are local extensions. Unused carousel/slider libraries, icons, analytics, external font requests, sample author metadata, and placeholder publication links are omitted. All media are local project recordings. Local asset hashes are included in each build's source-evidence manifest.
