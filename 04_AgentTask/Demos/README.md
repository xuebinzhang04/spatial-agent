# Agent task demonstrations

[spatial_agent](spatial_agent/README.md) is the single maintained research demo: [open the project page](spatial_agent/site/index.html), or run `python3 04_AgentTask/Demos/spatial_agent/run.py` from the SpatialAgent root.

It combines simulator/task/model selectors, definitions and variables, recorded media and trajectories, online environment APIs, model inference, city exploration, and mechanism illustrations. Delivery is a task on the dedicated SimWorld `gym_citynav` build, not a simulator name. Standalone MP4/PDF assets remain in the [media guide](spatial_agent/PRESENTATION.md).

Earlier standalone demo implementations are archived in `archive/agent-interaction/legacy-demos/`; there is no separate active DeliveryBench demo directory. See the [migration and verification record](../../archive/agent-interaction/2026-10-25-unified-demo.md).
