# 统一研究协议

## 环境、任务与 Agent

环境定义状态 S、动作 A、状态转移 T 与观察 O；任务定义初始状态 I、目标程序 G、约束 C 与预算 B。Harness 只能接收观察历史并调用动作。隐藏地图、未来事件、构造证书和验证器状态必须与策略隔离。用 `generate(family, seed, level, split, assets)` 生成带版本和内容哈希的 TaskSpec。

## 可组合性与任务准入

V1 目标语言为 `SEQ(ALL(predicates), ...)`，随后检查 `final` 谓词。一次状态转移至多推进一个阶段。谓词涵盖位置、物品、门、摆放与空间关系、配送与时间、电量、事件，以及受保护物体是否未被触碰。真正的组合要求前置条件、可达性、观察、共享资源或同时成立的终态约束形成依赖；只加长提示词不算组合。OR、UNTIL、COUNT 等算子须先定义语义并测试，方可加入。

能力机制、世界和目标程序应共同生成。实例准入前需检查实体、前置条件、连通性，并在最终预算和截止时间内重放可行轨迹。证书与 Agent 输入分开存储，同时审计完全重复项和数据划分。搜索超时应标为 `unknown`，不能标为 `unsolvable`。见证轨迹的长度是最优步数的上界；特权轨迹不证明受限观察下可解，也不证明预算已校准。

## 验证与奖励

根据真实状态及历史评分，不能依据模型自报、参考动作字符串或奖励值判断成功。检查时序、终态、受保护物体的触碰历史、资源和截止时间。提前或远程配送、穿越锁门、远程摆放、无限电量利用、伪造成功标志及终止后动作均应被拒绝。轨迹重放复用同一套转移代码，可选验哈希；因此仍需行为测试和跨后端一致性检查。区分成功、失败的 `stop` 与预算截断。

默认稀疏奖励仅在验证成功时为 1。可选势函数塑形为 `r' = r + γΦ(next) − Φ(current)`，包括截断在内的所有终止状态都令 Φ=0；应在相同折扣因子下与稀疏奖励对比。公开的固定动作目录／掩码不泄露隐藏状态下的动作合法性。非法动作消耗预算。训练器必须编码文本观察；可选 Gymnasium 封装本身不是完整 RL 训练流程。

## 难度与评估

结构难度由拓扑、目标数、依赖深度、关系数、可见性／记忆、事件、资源余量与动作预算余量控制。L1–L5 可复现，但要用策略实测校准。固定模型版本、Harness、观察、动作粒度、采样和预算后，按环境／级别报告成功率、失败类型、步数、token、耗时、pass@1 区间，以及 `pass@k = 1-C(n-c,k)/C(n,k)`（k≤n）。只有在确认生成器有效并建立固定均匀采样基线后，才能按学习前沿调整课程；现有采样器并非 PAIRED／PLR／ACCEL。

应区分实例、布局、谓词组合、规模、干预与后端的保留测试。当前精确任务／世界哈希无法检测图同构和近重复。调生成器与选检查点时不得使用最终测试或外部基准标签。同一任务的组式 RL 轨迹应固定 TaskSpec，并单独记录策略随机性。目前仅完成单任务表格 Q-learning 冒烟测试；模型 RL 和迁移仍是假设。实验细则见[迁移协议](TRANSFER_PROTOCOL.md)。
